# Порівняння технологій машинного зору для оцінювання пропорцій в ескізах

Код і результати експерименту до тез конференції.
Перевіряється, чи здатні традиційні показники (MSE, SSIM, Canny, Sobel) та ознаки моделі
Vision Transformer (ViT) відрізнити **зміну пропорцій** ескізу від **зсуву, масштабування та шуму**.

## Файли
| Файл | Призначення |
|---|---|
| `experiment.py` | Основний експеримент: підготовка ескізів, 18 варіантів кожного, шість показників подібності |
| `analyze.py` | Відтворює таблиці 1–2 і довірчі інтервали з `results/results.csv` |
| `make_figure.py` | Створює ілюстрацію (схематичний ескіз і його варіанти) |
| `results/` | Результати: `results.csv` (432 рядки), таблиці 1–2 |

## Дані
Вибірка: 24 ескізи (категорії `home`, `cat`, `cup`, `tree`, по 6). Ескізи отримано з відкритих
інтернет-джерел і **не включено в репозиторій** через авторські права.
Щоб відтворити експеримент, покладіть власні ескізи (чорні штрихи на світлому тлі) у структуру:

```
sketches/
  home/1.png ... 6.png
  cat/1.png ...
  cup/1.png ...
  tree/1.png ...
```
Можна також використати відкритий набір TU-Berlin (Eitz, Hays, Alexa, 2012; CC BY 4.0), змінивши
`SKETCH_DIR` і `CATEGORIES` на початку `experiment.py`.

## Запуск
```
pip install -r requirements.txt
python experiment.py          # створює results.csv, table_mean.csv, table_auc.csv
python analyze.py results.csv # таблиці 1-2 і довірчі інтервали
python make_figure.py         # figure_variants.png
```
Модель `google/vit-base-patch16-224-in21k` завантажується автоматично (потрібен інтернет, ~350 МБ).
Усі випадкові елементи фіксовані (`SEED = 42`).

## Показники (більше значення = більша подібність)
MSE (як 1 − MSE), SSIM, перекриття контурів Canny і Sobel (коефіцієнт Dice),
косинусна подібність ознак ViT: `ViT_CLS` (вектор CLS) і `ViT_patch` (усі фрагменти з позиціями).
